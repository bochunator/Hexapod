# Hexapod – Robocomp 2024 - Kraków AGH

A six-legged walking robot assembled and prepared for competition during RoboComp 2024 in Kraków, representing Spice Gears Academy (SGA). The project involved several weeks of hands-on work, including mechanical assembly, electronics soldering, hardware integration and software installation.
